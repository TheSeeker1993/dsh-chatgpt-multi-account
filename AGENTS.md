# Правила для AI

- Сначала прочти [docs/PROJECT.md](docs/PROJECT.md), затем нужные исходники. Это самостоятельный DSH-плагин, не web-приложение.
- Runtime: `index.js` → `multi/host.js`; UI: `client/index.js` (React через DSH loader). Не редактируй старые preview-папки или `client/reset-menu.snippet.js`.
- Не меняй явную привязку аккаунта к сессии, изоляцию credentials/refresh/replay и busy/lease-блокировки. Не добавляй fallback на другой аккаунт.
- Никогда не читай/публикуй реальные токены и не включай профиль DSH в репозиторий. Credentials остаются в DSH.
- Ручной сброс расходует ресурс: только выбранный аккаунт/credit, два отдельных подтверждения, никакого автоматического consume/retry/покупок. Тесты — только синтетические.
- DSH переписывает HTTP URL в `http://dsh.internal`: не сравнивай его Origin с адресом GUI. Сохраняй owner-auth и CSRF GET-token/custom-header.
- Минималистичный UI: четыре одинаковые панели (аккаунты/сбросы/рассуждения/модели), равные отступы; заливка аккаунта = оставшийся %, не всегда 100%. Не возвращай веер/центральную модалку/лишние подписи.
- Меняя `src/**/*.ts`, пересобери `lib/` (`npm run build`); `multi/*.js` и `client/index.js` исполняются напрямую. Цвета/шрифты — токены DSH; reduced-motion обязателен.
- Перед сдачей: `npm test`, `git diff --check`, `npm pack --dry-run`; проверь diff. UI-review и живая проверка DSH по возможности; отсутствие визуального теста укажи честно.
- Установка/перенос только через менеджер плагинов; не правь профиль вручную. Должна работать ровно одна реализация `chatgpt-session`. Не публикуй/не push без просьбы.
